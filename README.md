# EchoGPT – Manual Testing Project

## Project Overview
Performed manual testing of EchoGPT, an AI-powered chatbot, to evaluate its functionality, identify defects, assess user experience, and validate API behavior.

## Objectives
- Verify core chatbot functionalities.
- Identify functional defects and usability issues.
- Evaluate application behavior under different test scenarios.
- Validate API responses and error handling.
- Document defects and provide improvement recommendations.

## Testing Scope
- Functional Testing
- Positive and Negative Testing
- Boundary and Edge Case Testing
- UI/UX Testing
- API Testing
- Defect Reporting and Retesting

## Tools & Technologies
- **Postman** – API Testing
- **Jira** – Bug Tracking and Reporting
- **Microsoft Excel** – Test Case Documentation and Test Summary
- **Google Chrome** – Application Testing

## Project Deliverables
1. **Test Cases** – Documented test scenarios, test steps, and expected results.
2. **Bug Reports** – Identified defects with reproduction steps, severity, and priority.
3. **Test Summary Report** – Testing outcomes, execution status, and defect summary.
4. **API Testing Documentation** – API requests, response validation, and testing evidence.
5. **UI/UX Suggestions** – Recommendations to improve usability and user experience.

## Testing Approach
Followed a structured testing approach involving test scenario identification, test case design, execution, defect documentation, API validation, and result analysis.

## Project Outcome
Evaluated key application functionalities, identified and documented defects, validated API behavior, and proposed usability improvements.
